# سيرفر مرصد الأداء الجديد

بديل لسيرفر `marsad-kpi-live.karim87nu.chatgpt.site`، وبيرد بنفس الطريقة اللي الإضافة وصفحة الإدارة متعودين عليها.
**لسه متفعّلش:** الإضافة وصفحة الإدارة الحاليين لسه شغالين على السيرفر القديم، ومفيش أي حاجة اتغيرت فيهم.

## اللي فيه
- الموظفين (أسماء، أكواد، باسوردات أرقام فريدة)، ومستخدمي الإدارة بأدوارهم (مدير، مشرف، مشاهدة فقط).
- جلسات الموظفين من الإضافة، وكل الأحداث: مكالمات، بريك، جاهزية، انقطاع رصد.
- قواعد البريك: بريكين عاديين، 30 دقيقة إجمالي، والأول 15 + 5 سماح، وبعدها طلب بريك إضافي بموافقة المشرف.
- سجل أرابيكس من الموصل (كل 5 دقايق) أو من ملف Excel، ولقطات الطابور المباشر.
- المكالمات الفائتة، ومين كان متاح ساعتها بالثانية، ونسبة مكالمات السجل للموظف حسب التحويلة.
- كل أقسام صفحة الإدارة: المباشر، والتحليل، وملف الموظف، والمتابعات، والتقارير المحفوظة، والرسائل، والشيفتات، وسجل التغييرات.
- يوم البيانات من 9ص لـ 9ص، والتشغيل من 9ص لـ 3ص، بتوقيت القاهرة (التوقيت الصيفي محسوب).

## الباسوردات
الباسوردات القديمة بتشتغل زي ما هي. السيرفر القديم كان بيحفظها بطريقة PBKDF2، والسيرفر الجديد بيتأكد منها بنفس الطريقة. وأول ما الموظف أو يوزر الإدارة يدخل مرة، باسورده بيتحفظ تلقائيًا بالطريقة الجديدة. الباسورد الرئيسي للإدارة هو نفس `ADMIN_PASSWORD` بتاع السيرفر القديم، ولازم يتحط في `MARSAD_ADMIN_PASSWORD`.

## مفيش حاجة بتتمسح
- الموظفين ويوزرات الإدارة مفيش لهم حذف، فيه «إيقاف» بس. الحساب الموقوف بيفضل بباسورده وسجله ورسايله، ويرجع بـ «تفعيل».
- نقل البيانات القديمة (`old-to-sql.js` ومن صفحة الإدارة) بيضيف الناقص بس، ومش بيمسح ولا بيكتب فوق اللي على السيرفر الجديد.
- رفع Excel لسجل أرابيكس لو فيه مكالمات أقل من المحفوظ لنفس اليوم بيترفض.
- أول تشغيل للسيرفر من الصفحة (اختيار الباسورد الرئيسي) بيشتغل على سيرفر فاضي بس.

## التشغيل
```
cd server
npm install
MARSAD_SECRET=<نص عشوائي طويل> \
MARSAD_ADMIN_PASSWORD=<باسورد الإدارة الرئيسي> \
DEVICE_TOKENS=7000865f1220458f86506b41a97cab7d \
ALLOWED_ORIGINS=https://karim87nu-create.github.io \
DATABASE_PATH=/data/marsad.db \
npm start
```
على Railway: مشروع جديد من المستودع، والمجلد الأساسي `server`، وVolume متركّب على `/data`.

## نقل البيانات من نسخة القاعدة القديمة (الطريقة الأساسية)
```
DATABASE_PATH=/data/marsad.db npm run import-old -- /path/to/marsad-kpi-live.sqlite
```
- بيفتح الملف القديم للقراءة بس، ومش بيعدّل فيه حاجة. ولازم القاعدة الجديدة تكون فاضية.
- اتجرّب على نسخة 23-10-2026 الكاملة: اتنقلوا 28 موظف، و3 يوزرات إدارة، و1891 جلسة، و281,066 حدث، وسجل أرابيكس لـ 26 يوم، من غير ما حاجة تتساب.
- `node scripts/compare-old-history.js <old.sqlite> <new.db>` بيقارن مؤشرات كل يوم بطريقة السيرفر القديم: الـ 26 يوم طلعوا متطابقين بالظبط. ومكالمات كل موظف ومدة البريك بتاعته كمان متطابقة في كل الأيام.

## نقل البيانات من السيرفر القديم وهو شغال (احتياطي، من غير باسوردات)
```
OLD_URL=https://marsad-kpi-live.karim87nu.chatgpt.site OLD_ADMIN_PASSWORD=... \
DATABASE_PATH=/data/marsad.db npm run migrate -- 2026-09-01 2026-10-23
```
